Implementation process:

Using either a server or laptop you do not mind leaving running, boot the program in VScode or your environment of choice.

Replace the "Example Name" for the groupchat name in line 14 with your exact groupchat name.

The program should automatically detect your chrome version, if you do not have chrome installed you will need to install it.

Once the window opens there will be instructions to sign into Whatsapp Web. 

This needs to be completed within 60 seconds or the program will detect inactivity and shut down.

If this happens just run it again after closing the pop up window.

Once logged in the program should find your groupchat and send a test message that indicates that the bot is functional.

There are currently 4 times where the bot notifies the group, this was created for a charity organisation I am apart of so if you want to change the times or days or frequency you will need to edit the Autopy.py file directly yourself.

If you do edit times or frequency do not forget to also edit the test message (or remove it entirely if you like).
